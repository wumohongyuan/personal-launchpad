# Personal Launchpad

一个面向 Obsidian 的个人启动台插件：用一个可自定义、可同步的首页，放下计划、闪念、行动、复盘、训练与书库。

它不是某个人的固定成长剧本。新用户可选通用计划，也可设定自己的目标、名称与周期；所有记录仍是普通 Markdown 和 JSON 文件，数据始终留在你的 Vault 中。

## 安装

### 推荐：BRAT 自动更新

每台设备安装社区插件 **BRAT**，选择「Add beta plugin」，填入：

`wumohongyuan/personal-launchpad`

在 BRAT 中启用自动更新。每次发布新版本后，无需手动复制插件文件。

### 手动安装

下载 GitHub Release 中的 `main.js`、`manifest.json`、`styles.css`，放进 Vault 的 `.obsidian/plugins/personal-launchpad/`，再在 Obsidian 的「设置 → 第三方插件」中启用 **Personal Launchpad**。

## 公共计划系统

在「当前成长 → 编辑」中可选择：

- 84 天行动计划：适合建立行动、复盘与恢复节奏；
- 42 天专注计划：适合推进一个明确项目；
- 180 天个人成长计划：保留早期版本的完整阶段与交付物；
- 自定义周期：输入计划名称、目标、开始日期和 7–1095 天周期；
- 自定义计划模板：以“阶段名称 | 周数 | 任务”的形式编辑最多 8 个阶段，并自定义各周交付物。

顶部进度、阶段任务、交付物和周复盘会跟随所选计划变化。旧版本已在使用 180 天系统的用户会自动保留在该预设中；不会删除任何已有笔记、训练、闪念或书库数据。

## 功能

- 每日推送或自定义横幅话术，右上角齿轮集中设置；
- 单输入框闪念捕捉，按日期保存为 Markdown；待办型闪念可一键加入今日行动；
- 闪念收件箱：汇总跨日期待整理闪念，可转为今日行动或归档；
- 今日重点、可编辑和删除的行动清单、临时任务；
- 可选计划、自动进度、阶段任务、交付物模板与周复盘；
- 反馈 / 观察记录与周统计，可用于外部沟通、数据记录或个人发现；
- 书库、阅读进度与对应 Markdown 页面同步；
- 训练记录，显示本周次数、分钟数和最近体重；
- 主页定制：显示、隐藏、排序系统卡片，添加或删除文本、链接和计数器卡片；
- 交互式布局：桌面端通过卡片右上角拖动手柄直接排序；尺寸按钮可循环切换紧凑、标准、宽幅和全宽；平板、手机在「定制主页」中选择尺寸与顺序；
- 桌面 12 栏、平板双栏、手机单栏的响应式布局，支持深色模式和减少动态效果设置。

## 数据与同步

插件在 Vault 的 `个人成长系统/` 下创建配置、闪念、复盘、书库、训练和反馈 / 观察文件。这些都是本地可读的普通文件，可由 Fast Note Sync、Obsidian Sync 或其它 Vault 同步方案同步。

插件本身的更新与个人数据是两件事：通过 BRAT 或 GitHub Release 更新的是 `.obsidian/plugins/personal-launchpad/` 内的插件文件；同步工具同步的是 Vault 中的个人记录。

配置每一天首次修改时会在 `个人成长系统/配置/备份/` 留下前一份配置快照，方便在同步冲突后人工恢复。

## 发布与更新

每次版本更新都会递增 `manifest.json` 版本并发布同版本 GitHub Release，Release 附带可安装的三个文件。仓库不会提交你的 Vault 数据。
