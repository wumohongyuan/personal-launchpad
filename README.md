# Personal Launchpad 3.0 · 个人空间

一个可以按自己的习惯摆放的 Obsidian 工作台：随手记想法、写日记、整理知识、收藏读完的书，也把行动、成长记录和续费日期放在手边。

3.0 基于 [Home Pages](https://github.com/jepicaju862-lab/home-pages) 的真实源码继续开发，保留其多页面、卡片、拖动排序、缩放和原生配置界面。上游基线为 **0.3.1 / [`2f98a7c`](https://github.com/jepicaju862-lab/home-pages/tree/2f98a7c44432a5e077977535f94093487417c735)**。插件 ID 为 `personal-launchpad`，名称为「个人空间」，可与上游插件区分。

## 让工作台适合自己

- **贴近 Home Pages 的默认界面**：提供参考原版的紧凑工作台布局、精确到秒的时钟，以及「原版深色」「浅色」「跟随 Obsidian」外观设置；默认排列仍可自行调整。

- **DIY 页面与组件**：新建、重命名、排列页面；在「编辑工作台」中拖动卡片标题排序，拖右下角改变大小。也可以用按钮调整顺序与尺寸，齿轮设置标题、显示内容和组件参数。组件可以添加、复制或移除。
- **随手记与日记**：先输入再保存，不必先命名文件。支持随手记、日记、待办，按日期与类型回看，编辑记录、打开原文、提炼成知识。Ctrl / Cmd + Enter 保存，中文输入法组合输入期间不会误提交。
- **想法与行动**：把待整理的想法收好、转为待办，集中查看以前没做完的行动。记录正文使用原生 Markdown Callout，时间与类型作为小标题。
- **图书馆**：按想读、在读、已读管理书籍，记录进度、摘录与心得。读完后写下自己的理解，将书留在书架里；心得也能提炼成带来源的知识笔记。
- **成长与回顾**：成长计划、阶段交付、运动记录、周回顾和知识整理；保留上游的习惯、番茄钟、固定笔记和快捷入口等组件，可按需组合。
- **账本与会员订阅**：记录收入、支出与月度结余，维护会员或服务的续费金额、周期、到期日及提前提醒天数。确认「已缴费」会记一笔支出并推进下次到期日，同一账期重试不会记两次。

续费提醒在 **Obsidian 打开且处于前台**时检查；每台设备每天对同一订阅账期提醒一次。插件关闭时不提供系统推送，也不会自动扣费。当前账本支持人民币 CNY，界面输入元，保存和计算使用整数分。

## 安装与打开

从 [本仓库 Releases](https://github.com/wumohongyuan/personal-launchpad/releases) 下载 `main.js`、`manifest.json`、`styles.css`，放入笔记库的 `.obsidian/plugins/personal-launchpad/`，在 Obsidian 第三方插件设置中启用「个人空间」。清单声明最低 Obsidian 版本为 1.8.7。

点击侧栏房子图标，或在命令面板运行「打开个人空间」。也提供「随手记一条」「打开日记」「打开图书馆」「打开账本与续费提醒」「重新打开主页（恢复视图）」等入口。是否启动时打开，可在插件设置中调整。

升级时替换上述三个文件，保留自己的插件 `data.json`，然后重新启用插件或重启 Obsidian。首次进入 3.0 会提供适合记录、阅读和成长的默认页面，随后都可以自行修改。

## 数据保存与三端同步

默认目录如下。日记、知识库、复盘目录及个人资料根目录均可在插件设置中调整；修改目录只影响后续读写，不会自动搬迁已有文件。

```text
个人成长系统/
  日记/YYYY-MM-DD.md          随手记、日记、待办与重点
  知识库/标题.md              知识笔记与来源链接
  复盘/YYYY-MM-DD-周回顾.md    周回顾正文
  书库/书名.md                每本书的摘录、心得与阅读记录
  配置/workbench.json         书目、成长、运动及想法整理状态
  配置/finance.json           收支与订阅；归档保留原记录
  配置/launchpad.json         旧版配置，兼容读取并保留原文件
  闪念/                      旧版 Markdown 记录
```

正式记录保存在笔记库中的 Markdown 或 JSON 文件，沿用你现有的 Obsidian Sync、Fast Note Sync 或其他笔记库同步方案。电脑、平板、手机需要使用同一套库内容与保存目录，并分别安装、启用插件。插件不会自动配置或替代同步服务。

页面布局与插件偏好保存在插件的 `data.json`；布局能否跨端一致，取决于同步方案是否同步对应插件配置。未提交的草稿以及提醒去重状态保存在当前设备的本地存储，**草稿不跨设备同步**。换设备继续写之前，先把内容保存成记录。

文件队列与 `Vault.process` 保护本机写入顺序；稳定记录标识防止同次提交重复追加。不同设备同时离线编辑同一文件时，冲突处理仍取决于同步工具，插件不承诺自动合并。订阅按本地日期计算，月末及闰年续期保留原账期基准日。

## 旧版资料与恢复

旧版闪念和 `launchpad.json` 以兼容读取方式接入。首次修改相关资料时，写入新的 `workbench.json`，原始旧配置保留；已有书笔记和手写正文不会因升级被批量重写。旧版任务、书目、成长及运动记录可继续使用，旧版自由布局不会直接替代 Home Pages 的新布局。

配置或账本 JSON 损坏时会显示错误并停止相关写入，不用空白数据覆盖原文件。主页读取失败时先查看恢复提示，修复配置后在第三方插件中关闭再开启「个人空间」。

## 构建与验证

实际插件源码位于 `home-pages-personal/`。在仓库根目录执行：

```sh
npm ci --prefix home-pages-personal
npm run build
npm test
npm run test:upstream
node --test home-pages-personal/tests/finance.test.cjs
node scripts/package.cjs
```

根目录构建会编译 Home Pages 衍生源码、合并个人组件样式，生成根目录的三个安装文件与 `design/` 浏览器预览。根目录旧 `src/` 是历史实现，不参与 3.0 构建，也不进入插件发行包。不要使用上游旧的本地部署脚本打包本衍生版本。

运行 `npm run preview` 后打开 `http://127.0.0.1:4176/design/`。预览使用真实 HomeView 与个人数据服务，但 Obsidian API 由浏览器测试桩替代；演示数据与真实笔记库隔离。

验证覆盖数据追加、旧资料保留、写入失败和幂等重试，图书馆、日记与待办交互，以及 375 / 768 / 1024 / 1440px 浏览器响应式布局。记账测试还覆盖整数金额、损坏文件、月末、闰年及原子续费。浏览器和 API 模拟测试不等同于电脑、平板、手机原生 Obsidian 的完整实机验证。
